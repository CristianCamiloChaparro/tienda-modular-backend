## 4.1 Campos de texto libre que se muestran a otros usuarios: nombre de usuario, nombre/descripcion de producto y categoria, direccion de envio
Payload: <img src=x onerror="alert('XSS')">

$ POST /api/v1/auth/registro {"nombre":"<img src=x onerror=\"alert('XSS')\">Mario", ...}
{"id":4,"nombre":"Mario","email":"mario.lab@correo.com","rol":"CLIENTE"}
-> HTTP 201

$ (admin) POST /api/v1/categorias con el payload en nombre y descripcion
{"id":5,"nombre":"Resenas","descripcion":"Comentarios","creadoEn":"2026-10-27T22:27:19.444209513"}
-> HTTP 201

$ (admin) POST /api/v1/productos con imagenUrl javascript:
{"timestamp":"2026-10-27T22:27:19.528697472","status":400,"error":"Bad Request","mensaje":"Hay datos invalidos en la solicitud","ruta":"/api/v1/productos","campos":{"imagenUrl":"La imagen debe ser una URL http(s)"}}
-> HTTP 400

Content-Security-Policy: default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data: https:; object-src 'none'; base-uri 'self'; frame-ancestors 'none'; form-action 'self'
Alertas ejecutadas: ninguna
Consola: Executing inline event handler violates the following Content Security Policy directive 'script-src 'self''. Either the 'unsafe-inline' keyword, a hash ('sha256-...'), or a nonce ('nonce-...') is required to enable inline execution. Note that hashes do not apply to event handlers, style attributes and javascript: navigations unless the 'unsafe-hashes' keyword is present. The action has been blocked.
