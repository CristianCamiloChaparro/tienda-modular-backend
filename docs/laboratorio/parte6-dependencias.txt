=> Desde la red del laboratorio no se pudo descargar la base de vulnerabilidades (NVD respondio 403).
   Queda pendiente correrla en casa con una API key gratuita de NVD:
   ./mvnw org.owasp:dependency-check-maven:check -DnvdApiKey=<clave>
   Mientras tanto se activo Dependabot (.github/dependabot.yml) y se actualizaron las dependencias sin cambiar de version mayor.
